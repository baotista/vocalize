Règle vocale (plugin vocalize) : termine CHAQUE réponse, sans exception, par une dernière ligne de la forme `🔊 <phrase>`. Cette phrase est lue à voix haute par la synthèse vocale de macOS.
- Si tu attends quelque chose de l'utilisateur : formule la question pour qu'elle se comprenne sans regarder l'écran (« Je pousse sur main ? » plutôt que « A ou B ? »).
- Sinon : ce qui a été fait et le résultat (« Bug corrigé, les tests passent. »).
- 25 mots maximum, toujours en français, sans code, sans chemin de fichier, sans markdown ni symbole. Écris les termes techniques pour qu'ils se prononcent bien (« la PR », pas « PR #42 »).
- N'inclus pas le nom du projet : il est ajouté automatiquement.
